# ☕ java-core-journey

A structured personal workspace dedicated to mastering core Java syntax, algorithmic thinking, and Object-Oriented Programming (OOP) principles from the ground up.

---

## 🎯 Purpose of the Repository

This repository documents my daily progress in Java. The goal is to:
* Move beyond theory by writing clean, practical console applications.
* Build strong problem-solving habits using core programming fundamentals.
* Understand memory management, best practices, and clean code conventions early on.

---

## 📚 Curriculum & Progress

- [x] **Basic Syntax & Data Types:** Primitive types (`int`, `double`, `boolean`, etc.), variables, and type casting
- [x] **Operators & Expressions:** Arithmetic, relational, logical operators, and precedence
- [x] **Console I/O:** Reading user input via `Scanner` and handling system resource leaks
- [ ] **Control Flow:** Conditional logic (`if-else`, `switch-case`)
- [ ] **Loops & Iteration:** `for`, `while`, `do-while` constructs
- [ ] **Arrays & Data Collections:** 1D/2D arrays, dynamic sizing with `ArrayList`
- [ ] **Methods & Modular Code:** Custom methods, parameters, return values, method overloading
- [ ] **Object-Oriented Programming (OOP):**
  - Classes, Objects, and Constructors
  - Encapsulation (Access modifiers, Getters & Setters)
  - Inheritance & Polymorphism
  - Abstraction & Interfaces
- [ ] **Exception Handling:** Robust input validation, `try-catch`, and `try-with-resources`

---

## 💡 Key Learnings & Engineering Notes

* **Resource Management:** Closing I/O streams properly (`Scanner.close()` or using `try-with-resources` blocks) to prevent background memory leaks.
* **Stream Handling:** Working with standard console streams (`System.in` and `System.out`).
* **Type Conversion:** Handling precision differences between integer and floating-point arithmetic (e.g., proper division casting).
